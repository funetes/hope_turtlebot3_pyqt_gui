# Goal

- PyQt 기반 ROS 2 GUI 프로그램 작성
- TurtleBot3 배터리 잔량 및 전압 표시
- /cmd_vel 값 모니터링
- TurtleBot3 주요 토픽 상태 표시
- 경유점 등록 및 선택 이동 기능 구현
- 2개 이상의 trajectory 선택 주행 기능 구현
- gTTS 기반 음성 출력 기능 구현
- bringup, nav2, teleop 실행 버튼 추가
- 프로그램 상태 및 이벤트 로그 출력
- 팀별 자유 기능 추가


# 공통 필수 기능

- 로봇 상태 표시 영역 [o]
    - 연결 대기 [v]
    - 로봇 연결 완료 [v]
    - bringup 실행 중 [v]
    - nav2 실행 중
    - teleop 실행 중
    - 경유점 이동 중 [v]
    - trajectory 주행 중
    - 목표 지점 도착 [v]
    - 장애물 감지 -
    - 오류 발생 -
- 배터리 및 전압 표시 영역 [o]
    - 전압
    - 잔량 [v]
    - 상태 메시지
    - 저전압 경고
- /cmd_vel 표시 영역 [o]
    - linear.x [v]
    - angular.z [v]
- ROS 2 토픽 모니터링 영역 [o]
    - TurtleBot3에서 사용하는 주요 토픽 중 3개 이상을 선택하여 GUI에 표시합니다.
    - 현재 위치 x, y [v]
    - 현재 방향 yaw [v]
    - LiDAR 최소 거리
- 경유점 등록 및 이동 영역 [o]
    - 경유점 이름 [v]
    - x 좌표 [v]
    - y 좌표 [v]
    - yaw 방향 [v]
현재 navigation 상태 [?]
현재 goal 위치
- trajectory 선택 및 실행 영역 [o]
    - trajectory 선택 콤보박스
    - 선택한 trajectory 정보 표시
    - trajectory 실행 버튼
    - trajectory 정지 버튼
    - 현재 이동 중인 waypoint 표시
    - trajectory 완료 로그 출력
- gTTS 출력 영역 [o]
    - 텍스트 입력창 [v]
    - 언어 선택 옵션 [-]
    - TTS 출력 버튼 [v]
    - 출력 상태 표시 [-]
    - 로그 출력 [v]
- bringup/nav2/teleop 실행 버튼 영역 [o]
    - Bringup 실행 / 종료 [v]
    - Nav2 실행 / 종료 [-]
    - Teleop 실행 / 종료 [v]
    - 긴급 정지 [-]
- 로그 출력 영역 [o]
